# Manually Reviewed Question Options

These files contain the manually reviewed Arabic and English options for all
3,311 multiple-choice questions in `data/questions.xlsx`.

Each question was read in full and reviewed section by section. Distractors
were authored to match the question's exact semantic type and context. The
correct answer text and `correctAnswerIndex` were preserved.

The files are split into smaller parts only to make human review manageable.
They are the review record, not generated option pools or classification rules.
